## 🚀 Quick Deploy to Vercel

### 1. Update API Keys
Edit `api/gemini.ts` and replace:
- `YOUR_GEMINI_API_KEY_HERE` with your Gemini API key
- `YOUR_YOUTUBE_API_KEY_HERE` with your YouTube API key

### 2. Deploy
```bash
npm install -g vercel
vercel --prod
```

## 🔑 Get API Keys

**Gemini API**: [Google AI Studio](https://aistudio.google.com/)
**YouTube API**: [Google Cloud Console](https://console.cloud.google.com/) → Enable YouTube Data API v3
